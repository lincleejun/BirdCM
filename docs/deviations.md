# 实现与设计的出入

记录实现第 1、1.5、2、3 步时与 `design.md`（含第 9 节修订）不一致的地方和理由。

1. **解码方案选了第三种：RAW 内嵌的全尺寸 JPEG。** §9 要在 (a) 一次全尺寸解码、(b) 半尺寸 + 头部再全尺寸解码之间二选一。
   实测发现 A7 IV 的 ARW 里带一张 7008 × 4672 的相机 JPEG（`JpgFromRaw`，约 2.2 MB），用 Pillow 的 DCT 缩放解到半尺寸只要
   约 0.04 秒，而且只读文件的约 6%（主人的照片在 USB 机械硬盘上，读整个 39 MB 的 ARW 就要约 0.17 秒）。
   同样 120 张、4 个进程：内嵌 JPEG 50.8 张/秒，半尺寸解码 8.9 张/秒，全尺寸 3.7 张/秒（`perf.md`）。
   所以默认用 (c)，内嵌 JPEG 长边不到 2048 时（例如 Lightroom 导出的 DNG）回退到 (b) 的半尺寸解码。
   以后的头部清晰度可以直接在同一张全尺寸 JPEG 上裁头部，不需要再 demosaic；但它是相机处理过（降噪、锐化）的图，
   清晰度阈值要在它上面定，这一点留给清晰度调研确认。
2. **OWLv2 的处理器配置文件不进清单。** 上游 `config.json`（414 字节）除默认值外只有四个数，直接写在 `detect.py`；
   唯一的提示词 "a bird" 预先分好词（`[49406, 320, 3329, 49407]`）；图像预处理（灰 0.5 补成方形、缩到 960、CLIP 均值方差）
   在设备上自己做，比 `Owlv2Processor` 快得多。和 `Owlv2Processor` 对比过：同一帧的框位置差 < 0.005、把握差 < 0.03
   （`tests/test_models_smoke.py`）。效果等同于"写进清单并固定版本"，而且运行时完全不联网。
3. **`BIRDCM_MODEL_DIR` 可以是多个目录**（用 `:` 分隔），因为开发时模型分在 `release/` 和 `heads-repo-release/` 两处；
   缓存目录 `~/Library/Caches/BirdCM/models` 总是最后一个查找位置。每个文件都校验 sha256（按路径 + 大小 + 修改时间记住结果）。
4. **队列不是字面上的"三段有界队列"。** 只有一个调度线程，它同时是唯一的模型线程：解码任务提交给进程池，最多
   2 × 进程数个在途（这就是背压）；解码完的帧凑批（满一批、或第一张等了 200 毫秒、或后面没有了）送 GPU；exiftool
   在一个辅助线程上提前读。所有等待都带超时并检查停止标志，没有会永久阻塞的 `put/get`。停止时：不再提交，正在 GPU 上的
   那一批做完并提交，其余已解码或在途的结果丢弃，行退回 `queued`。这满足 §9 的语义，代码更少。
5. **检测模型在 GPU 上用 float16。** 120 张对比 float32：框数完全相同，主框 IoU 最小 0.994；速度快约 20%。
   BioCLIP 塔也是 float16，名录矩阵乘法和 softmax 用 float32；与 `examples/identify.py`（float32）在同一批裁图上前五与概率一致到小数点后两位。
6. **"不确定 / 只到属"规则（只凭图像，地区修正之前）**：第一名 ≥ 0.5 且领先第二名 ≥ 0.3 → 报到种；否则若同属概率合计
   ≥ 0.6 → 报到属；否则"不确定"。沿用 Gardener 的常量（`tower.py`），等地区修正接入后由调研结果替换。
7. **中文名**：`engine/birdcm/data/names-zh.csv`，取自 Gardener 随附的 Wikidata 标签表（CC0），只保留名录里的鸟，
   覆盖 11,172 种中的 5,330 种（48%）；没有中文名的显示英文名。
8. **对焦点**：`FocusLocation` 按它自带的宽高（7008 × 4672）归一化，不用 rawpy 的尺寸（7028 × 4688）。距中心一个像素以内的、
   宽高为 0 的、越界的都记为不可信。主人 1,947 张 ARW 里：65 张是中心默认值，3 张宽高为 0，没有缺失。
   这批和另外几个文件夹里都没有竖拍 ARW，竖拍的旋转映射只用单元测试（真实像素旋转）验证过，**未在真实竖拍照片上验证**。
9. **排队行**：按 §9 只显示文件名；选中排队中的照片时，按需从内嵌 JPEG 生成预览、用 exiftool 读拍摄信息。
10. **地区列表**只有名字（`app.py` 里的小表），代表坐标随 `geo.py` 一起来。
11. **一个扫描在最后一批时被停止**：照片都已处理但扫描停在 `paused`，按"继续"后立即汇总完成（有测试）。
12. **美学**：没有发布的美学头文件（`distill/aesthetic.py` 运行时用 EVA 数据现拟合），所以第二遍整图过塔没有做，
    `aesthetic` 字段为空、界面显示"待定"。清单里没有这一项。
