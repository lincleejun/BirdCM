# 需求文档：移动版（单张识别）

状态：草稿，2026-11-17。写给主人确认。标了"待定"的地方需要主人拍板，标了"未验证"的数字还没在真机上量过。
调研见 `notes/mobile-feasibility.md`。

## 1. 要解决的问题

在手机上打开一张鸟的照片，立刻知道：这是什么鸟、少不少见、眼睛在哪。不联网也能用，照片不离开手机。

## 2. 用户和场景

- 用户：主人自己，以及其他拍鸟的人。
- 场景：打开 App → 从相册选一张 → 等一两秒 → 看结果。
- 一次一张，不批量。
- 先做 iOS，Android 之后再说。

## 3. 流程

1. **选照片**：从系统相册选一张。
2. **读拍摄信息**：照片里的时间和 GPS。照片没有 GPS 时用手机当前定位；定位也没有时让用户选地区。
3. **找鸟**：检测模型自动找出鸟的框。手机照片没有对焦点信息，多只鸟时选最大的那只，用户可以点另一只切换。找不到时让用户手动框。
4. **看鸟**：BioCLIP 一遍给出鸟种、眼和嘴的位置、是否在飞。
5. **结合地区和日期**修正鸟种。
6. **稀有度**：查随 App 装好的表（GBIF 记录数、IUCN 等级）。
7. **显示结果**。

不做的事：不批量、不标星（星级是一批照片互相比出来的，单张没法定）、不认兽类、不上传照片。

## 4. 功能要求

### 4.1 输入
- 相册里的一张照片（JPG、HEIC；能读的话也支持相机导入的原片，待定）。
- 时间：取照片的拍摄时间。
- 地点：照片 GPS → 手机定位 → 手动选地区。只用到"国家 + 州 / 省"这一级。
- 定位权限只在照片没有 GPS 时才请求，用户拒绝也能用。

### 4.2 结果页

| 内容 | 说明 |
|---|---|
| 照片 | 画出鸟的框和眼睛位置。信息直接排在照片下面，上下滑动查看，不盖在照片上（主人 2026-11-17 定） |
| 鸟种 | 中文名、英文名、学名、把握；分不清时只报到属 |
| 其他可能 | 第 2 到第 5 名，可以点开 |
| 是否在飞 | 是 / 否 |
| 稀有度 | 当地当月：常见 / 不常见 / 少见 / 罕见 |
| 受威胁等级 | IUCN：无危 / 近危 / 易危 / 濒危 / 极危 |
| 拍摄信息 | 相机、镜头、焦段、光圈、快门、ISO、曝光补偿、时间、地区（主人 2026-11-17 定） |

- 把握低时明确说"不确定"，不硬给一个名字。
- **历史记录（主人 2026-11-17 定）：** 每次识别完自动记下来，不用点保存。首页能看到历史，点开能重新看结果，可以删除单条或清空。历史只存在手机上。
- 分享成一张图。**待定。**

### 4.3 模型的下载
- App 本体很小。模型（约 0.65 GB）在第一次打开后下载，默认只在 Wi-Fi 下。
- 下载前告诉用户体积。下载完成前不能识别。

### 4.4 性能目标（全部未验证，是目标不是实测）
- 选完照片到出结果：不超过 2 秒。（调研推算 iPhone 上 BioCLIP 每张 0.1–1 秒，加检测。）
- 第一次加载模型：不超过 10 秒。
- 识别过程中 App 不被系统因内存杀掉。
- 鸟种第一名命中和电脑版一致（约 92%）。

## 5. 用到的模型

| 环节 | 模型 | 体积 | 状态 |
|---|---|---|---|
| 找鸟 | 小检测模型（D-FINE 或 RT-DETR，待定） | 15–80 MB | 电脑上对比进行中；手机上没试过 |
| 鸟种、眼、嘴、飞 | BioCLIP 2.5 看图部分，8 位 + 三个小头 | 0.63 GB | 电脑上已验证；手机上没试过 |
| 鸟名向量 | 11,172 种 | 约 23 MB | 已有 |
| 地区修正 | BirdNET 地理数据 | 待量 | 手机上能不能跑没查过 |
| 稀有度 | GBIF + IUCN 的表 | 估计几 MB | 生成中 |

美学分第一版不做（需要多跑一遍模型，而且它只比随机好一点）。**待定。**

## 6. 技术路线（来自调研，未实测）

- 用 Core ML。把 BioCLIP 转成苹果的格式，同时输出"鸟种向量"和"第 15 层"，三个小头接在后面。
- 权重 8 位。要从原始模型重新压一遍，压完重新测准确率。
- 模型用系统的后台资源下载，不放进安装包。
- 在真机上分别试"神经网络芯片"和"显卡"两种跑法，用快的那个。

## 7. 风险

- **内存。** 0.63 GB 的文件加载后可能展开到 1.26 GB。苹果不公布 App 的内存上限。这是最大的风险。
- **用不上神经网络芯片。** 公开的例子里最大的模型只有我们的一半大。退回显卡会慢几倍。
- **没有任何人公开过这么大的模型在手机上的实测。** 上面的时间全是推算。
- **手机照片里的鸟通常更小、更糊**（没有长焦）。准确率可能比评测集低，要用手机拍的照片另测。
- **检测框里没有清楚的鸟时，眼和飞行会乱给结果。** 和电脑版同一个问题。

## 8. 第一步：最小验证

在做完整 App 之前，先回答三个问题。需要一台能连 Xcode 的 iPhone。

1. BioCLIP 转成 Core ML 后，在真机上每张要多久？
2. 内存峰值多少？会不会被杀掉？
3. 准确率是否还是 92% 左右？

三个数都过关，再做界面和其他环节。任何一个不过关，退路是：
- 电脑上算，手机只看结果；或
- 继续做小模型（现在 60%，88 MB），等它追上来。

## 9. 验收

- 真机上选一张照片到出结果不超过 2 秒。
- 连续识别 50 张不崩溃。
- 评测集上鸟种第一名不低于 90%（在真机或同样格式的模型上测）。
- 断网时能完成识别。
- 照片不离开手机。
