# 评测（`birdcm eval`，2026-11-17）

```
uv run birdcm eval --groundtruth /Users/outman/workspace/personal/bioclip-bird/eval/groundtruth.csv \
    --photos /Users/outman/workspace/personal/bioscan/data/inat --kinds bird,mammal --out eval.json
```

- 评测集：bioclip-bird 的 `eval/groundtruth.csv`，1,571 张 iNaturalist 照片（鸟 1,046、兽 525）。照片已在本机
  `bioscan/data/inat/`（gardener 的数据目录），全部 1,571 张都在，前 50 张核对过 sha256；只读，没有下载。
- 跑的是 BirdCM 的真实流水线（`Engine.run`）：内嵌 JPEG / Pillow 解码 → OWLv2 8 位（float16）→ 每个框过 BioCLIP 8 位塔
  （鸟种、眼嘴、飞行、"清楚的鸟"判断）→ 在通过的框里选主体 → 头部清晰度、美学。指纹 `e0d6c7a389f9c738`。
- **没有地区修正**（BirdNET 先验还没接）：鸟种是只看图像的结果。PRD 的 91% 目标是含地区先验的口径，不能直接比。
- 分母固定：每张鸟图都算，解码失败、没有框、被淘汰、名字对不上的都算错。M4 Max，214 秒（1,571 张，GPU 与其他任务共用）。

- 参考：调研笔记（`notes/clear-bird-gate.md`）在 gardener 的检测 + 同一个塔、无地区先验下测到第一名 84.13% → 84.03%（加把关后）。
  这里 84.23% 与之相当；两者的检测器、裁剪和计分口径不同，只能粗比。
