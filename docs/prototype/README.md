# 观羽 · 桌面与手机原型

直接在浏览器打开 [桌面审片](desktop.html) 或 [手机认鸟](mobile.html)。两个页面都从本地文件运行，图片来自同目录的 `img/`。

> `img/` 里的示例裁图是作者自己拍的照片，没有公开发布；公开仓库里没有这个目录，原型页面的照片框会是空的。
页面用「原型 · 示例数据」标明当前内容。功能范围见 [桌面需求](prd-desktop.md) 和 [手机需求](prd-mobile.md)。

## 共同的视觉与交互

- 产品暂用名「观羽」。桌面使用暖白纸色、松绿操作色和炭绿照片底板，手机沿用这套色彩。暗色版用深松绿纸面和浅绿操作色，跟随系统切换。
- 中文主标题用系统宋体，控件和结果正文用系统黑体，曝光参数、计数和文件名用等宽数字。照片负责建立视觉重点，细线只用于分隔表单、列表和相机信息。琥珀色用于星级，陶红色用于少见或罕见、不确定与待定。
- 每一步只有一个填色主操作。触摸控件至少 44 × 44 CSS 像素，底部留出安全区。键盘有可见焦点，弹层支持 Escape，系统开启减少动态效果时取消面板过渡。
- 保留原裁图上核对过的标注坐标。黄色框标鸟，红圈标眼睛，桌面的青色方块标相机对焦点。暗色描边帮助线条在亮底和暗底上保持可辨。手机识别时整张照片按比例显示，缩放时照片与标注同步。
- 两端都把焦距、光圈、快门、ISO、曝光补偿排成一行，相机、镜头和拍摄时间放在详情。示例索尼套装为 α7 IV（ILCE-7M4）与 FE 200-600mm F5.6-6.3 G OSS。参数参考 [样本元数据](sample-exif.txt)，例如 `600 mm  f/6.3  1/1000 s  ISO 250  0 EV`。桌面另显示跟踪对焦模式。手机拍摄示例用 iPhone 15 Pro 主摄，分别写实焦距与等效焦距。
- 识别范围是鸟，姿态只显示在飞或不在飞。把握不足时以「不确定」为标题并展示候选。能判断到属时同时标出属名，具体鸟种和 IUCN 等级留空。已确认的结果显示中英文名、学名和把握。

## 桌面审片

1. **选片设置。** 左边选文件夹、是否包含子文件夹、国家和州 / 省、留片比例，右边展示角鸬鹚样片。照片有位置时以照片为准。点击「选择示例文件夹」解锁「开始」。比例提供宽松 40% / 30%、标准 30% / 30%、严格 20% / 30%、待定的更严 10% / 20%，以及默认 25% / 30% 的自定义档。自定义两档合计上限为 100%。比例是批内目标，会受连拍上限和鸟种保底影响。
2. **边扫边看。** 点「开始」直接进入审片页，46 张照片立即入列，先显示淡化缩略图、文件名和曝光参数。每批最多三张，由「排队中」变为「识别中」，随后填入鸟种、在飞状态、眼部清晰度与稀有度。顶部状态行显示已完成张数、当前步骤和细进度条，汇总同步更新已扫描张数、鸟种和少见或罕见的鸟。扫完后状态行收成「已完成」。
3. **暂停、筛选和排序。** 点「停止」保留已识别结果，剩余行显示「未扫描」，「继续」从下一张未扫描的照片接着处理。「换一批」返回选片设置。鸟种、在飞和稀有度筛选只匹配已识别结果。按识别结果排序时，未完成的照片仍按队列顺序留在末尾。右侧预览随选中照片更新，排队时也能看大图和拍摄参数。可以关闭列表和预览上的标记。
4. **深入看一张。** 已识别的照片可以马上打开详情。上下方向键可在照片列表移动，回车查看已扫描照片的详情，弹窗内用左右方向键在已扫描照片之间翻页。详情有全尺寸标注、图例、候选、眼睛可见性与清晰度、在飞状态、美学参考分、稀有度、IUCN、连拍组和完整拍摄信息。眼部清晰度以 0.70、0.45 为界，美学分仅供参考。
5. **整批标星与导出。** 扫描期间各行显示「待定星级」，星级筛选、星级排序和导出暂不可用。扫完后统一按原规则计算星级和组内排名，显示各星级及淘汰张数，并开放筛选、排序与导出。使用默认队列顺序时切换到星级排序，手动选的其他排序会保留。每张照片仍有一句标星理由，连拍组三星最多两张，每个识别分类至少保留一张两星。CSV 与 JSON 可下载全部或当前筛选结果，均包含拍摄参数，CSV 带 BOM。观鸟清单、写入 XMP 与网页报告显示「以后 · 待定」。

## 手机认鸟

- **首次打开。** 先说明离线识别包约 650 MB，默认仅 Wi-Fi，下载中显示用量和进度。完成后在浏览器允许时记住本机演示状态。「首次打开」会重置这项记录。
- **识别历史。** 首页显示缩略图、鸟种或「不确定」、拍摄时间和地区，按识别先后倒序排列。结果一出来就记一条，点记录可直接重开，补充地区和切换的主体也会保留。短距离左滑露出「删除」，长距离左滑直接删除。结果页「…」也可删除单条，首页「…」里的「清空历史」需再确认。原型历史只保留在当前页面的内存里，重新加载会恢复三条演示样例。
- **相册和识别。** 「从相册选择」固定在首页底部。示例相册的六张照片点一张就开始识别，识别中保持所选照片可见。结果页「再选一张」直达相册，此时取消可返回原结果。
- **结果页。** 照片以原比例铺满宽度，往下滚依次看到鸟名和把握、在飞状态与稀有度、IUCN、其他候选、曝光参数和完整拍摄信息、拍摄地区。顶部「历史」返回首页，底部「再选一张」随时可用。「分享图片 · 待定」在「…」里。照片在原尺寸下支持从照片开始上下滑动页面，双击、双指捏合或点缩放按钮可放大。放大后可拖动，也可在缩放按钮获得键盘焦点时用方向键平移。
- **特殊情况。** 多只鸟默认查看最大的那只，其他鸟框是白色虚线。点鸟框、鸟序号或在未放大的照片上左右滑动都能切换。把握低时展示「不确定」，下方直接列出五个候选。缺少位置时在拍摄地区显示「补充地区」，可用模拟手机定位，或手选国家和州 / 省。找不到鸟时在照片上画框再识别，键盘也可选择用整张照片重试。
- **演示入口。** 桌面浏览器把状态切换放在手机框旁，窄屏放在手机界面下方。「首页 · 空历史」只预览空状态。控制台可用 `go('home')` 查看历史，或用 `demoResult('star')` 打开多鸟示例并记一条识别结果。

| 相册样例 | 可体验的状态 |
| --- | --- |
| 白腹鱼狗 | 常规识别、相机导入的拍摄参数 |
| 两只紫翅椋鸟 | 在相邻两块裁图之间切换主体 |
| 雌性黑鹂 | 低把握、打开候选 |
| 棕腹长尾霸鹟 | 手机拍摄、补充地区 |
| 模糊的雁 | 手动画框或用整张照片重试 |
| 飞着的角鸬鹚 | 在飞 |

## 示例数据与本地验证

- 桌面以 15 组裁图展开为 46 张模拟连拍。同组帧共用裁图，其中一张用模糊滤镜展示头部过糊的情况。
- 文件夹、系统相册、下载、设备定位与识别均为模拟。拍摄时间、参数、识别把握、候选、清晰度和稀有度为示例值。补充地区会演示从初步把握到结合地区的界面变化。稀有度示例沿用加利福尼亚州 11 月的数据设定。
- 桌面控制台的 `selfCheck()` 检查不同留片比例下的张数、连拍三星上限、鸟种保底与星级说明，并恢复当前比例。
- 桌面控制台可运行 `demoScanAt(24)` 查看 46 张中已有 24 张完成的队列，演示画面会停在该进度。`finish()` 直接打开完成态。
- 已在离线 Chromium 中检查两端主流程、浅色和深色、320 像素宽的结果页及模拟手势，并运行脚本语法检查与外部地址检查。iPhone 真机上的浏览器手势和原生功能尚未实测。
