# Bird Value（主人的设计，2026-11-19）

设计来自主人和 ChatGPT 的对话。这里只记录它在观羽里怎么落地、目前做到哪一步。旧稿 `docs/design-bird-score.md` 已经被这份取代。

## 公式：照主人的 `scoreBird` 实现，常数不变

代码在 `engine/birdcm/value.py`，测试在 `engine/tests/test_value.py`。

- 鸟种基础分 = tanh_score(0.7 G + 0.3 C)，用于搜索时没有选地点的情况。
- 地区价值 = tanh_score(max(0.95 R + 0.05 基础, 0.90 基础 + 0.10 R))。
- R = 0.75 L + 0.10 N + 0.05 T + 0.10 H。
- tanh_score(q) = 1 + 9 · (tanh(k(q − c)) − tanh(−kc)) / (tanh(k(1 − c)) − tanh(−kc))，其中 k = 3，c = 0.65。

几条约定：
- 照片得分 = 鸟的价值 + 影像加分（0–0.6），两个数分开显示。"9 分鸟"只指鸟的价值。
- 是不是生涯新种，不影响价值。
- 分数存的是不四舍五入的原值，显示时保留两位小数。

## 六个因子在我们的数据里对应什么

| 因子 | 设计里的含义 | 观羽现在用的数据 |
|---|---|---|
| G 全球稀缺 | 全球种群、分布范围 | 这个月这种鸟在**最容易见到的地区**的 GBIF 记录占比 |
| C 保护 | IUCN + 当地法律保护 | 只有 IUCN。**没有中国国家重点保护名录**。IUCN 等级来自随工程分发的 `engine/birdcm/data/iucn.csv`（CC BY 4.0） |
| L 当地稀缺 | 县级全年 checklist 报告率 | **州、省**级全年 GBIF 记录占比（×30 近似换算成报告率） |
| N 大范围稀缺 | 州、省或国家 | 国家级全年占比 |
| T 季节异常 | 本周相对全年偏低多少 | 本月占比相对全年占比偏低多少 |
| H 历史纪录 | 独立出现事件数 | 这个州、省有记录的总条数（不是独立事件数） |

**没有记录不等于最高分**，按三种状态处理，测试已覆盖：
- 搜索时，这个地区从没有过记录：返回 `insufficient-data`，不给地区分。
- 照片里拍到了：按地区最低的占比（相当于只有 1 条记录）计分，状态是 `pending`（待核实），主人确认鸟种后才算正式分数。
- 有记录：状态是 `estimated`，正常计分。

## 用主人的验收例子在真实数据上验证

脚本是 `engine/bench/bird_score/cases.py`。

| 例子 | 主人期望 | 现在算出 | 结论 |
|---|---|---|---|
| 朱红霸鹟，Cupertino | 8.5–9.5 | 1.82 | ✗ 数据只到州：它在南加州是繁殖鸟，加州全年有 6.7 万条记录 |
| 朱红霸鹟，南加州繁殖地 | 3–5 | 1.83 | 和 Cupertino 一样，因为是同一个州 |
| 白尾海雕，大连冬季 | 6–7.5 | 2.10 | ✗ 缺中国国家一级保护这一项；它在欧洲很常见，所以 G = 0 |
| 白尾海雕，Cupertino（拍到） | 9–10 | 9.14 | ✓ |
| 喜鹊，加州，搜索 | 不应自动高分 | 资料不足 | ✓ |
| 家麻雀，加州 | 低 | 1.15 | ✓ |
| 斯氏铁爪鹀，加州 | 高 | 7.50 | ✓ |
| 加州神鹫（极危），加州 | 高 | 4.21 | 偏低：加州有放归种群，记录很多 |

分布脚本是 `engine/bench/bird_score/value_distribution.py`，用的是设计里的演示常数 k = 3、c = 0.65：

| 地区和月份 | 6 分以上的鸟种 | 8 分以上的鸟种 | 9 分以上的鸟种 | 按观察次数，6 分以上 |
|---|---|---|---|---|
| 加州 11 月 | 190 种 | 113 种 | 51 种 | 0.03% |
| 英国 5 月 | 326 种 | 184 种 | 132 种 | 0.06% |
| 北京 11 月 | 7 种 | 1 种 | 0 种 | 0.02% |

演示常数在我们的数据上偏严：几乎所有观察都在 1–3 分，和"大多数人最好的鸟在 6–7 分"对不上。正式的 k 和 c 要等 L 有了县级数据以后再定。设计里也说了，参数要用真实的稀有鸟纪录来拟合。

## 卡在哪里，需要主人决定

1. **县级数据**：现在的稀有度表最细到州、省，这个表在 `bioclip-bird/distill/rarity_global.py` 里生成。GBIF 支持按县查询（gadm 二级行政区），可以只补美国县和中国地级市。代价是：
   - 约 3,400 个区 × 12 个月，按每秒 1 次请求，要跑 10 小时左右。
   - 表会变大，要看手机能不能装下。
2. **中国保护名录**：《国家重点保护野生动物名录》（2021）是公开的，可以做成一张表，并入 C。
3. **地点模型帮不上忙**：BirdNET 地点模型在 Cupertino 给朱红霸鹟 0.12，给铁爪鹀 0.54，给加州神鹫 0.14。它反映的是"可能出现"，不是"有多常见"，不能当 L 用。

## 没做的部分

- 设计里的 PostgreSQL 表、API、`value_event`、Bird Heat：观羽是离线应用，没有后端。
- α 平滑：GBIF 的分母是百万级，平滑几乎不起作用；表里已经有退到国家数据的机制。
- 手机端和界面：要等上面的数据问题定下来再做。
